# South Indian Restaurant Sales Analytics Dashboard

## Project Overview
This project presents an interactive Power BI dashboard for analysing South Indian restaurant sales.

## Objectives
- Analyse total restaurant revenue and orders.
- Identify top-selling dishes.
- Compare revenue by dish category.
- Analyse customer ratings and order types.
- Compare restaurant branch performance.

## Tools and Technologies
- Microsoft Power BI
- Microsoft Excel
- DAX (Data Analysis Expressions)
- GitHub

## Dashboard Features
- KPI cards
- Monthly Sales Trend
- Top-Selling Dishes chart
- Revenue by Dish Category chart
- Orders by Type chart
- Customer Rating chart
- Branch Performance table
- Branch Location map
- Interactive slicers

## Files
- Power BI dashboard file (.pbix)
- Restaurant sales dataset (.xlsx)
- Dashboard screenshot (.png)

## Dataset
The project uses a sample restaurant sales dataset.
